# SafePDFHub Support Page

Route: `/support`

`/donate` redirects to `/support` so both names remain discoverable.

## Current implementation

- privacy-first support messaging matching the landing page
- global currency selector for USD, EUR, GBP, CAD, AUD, AED and INR
- localized contribution suggestions per currency
- custom amount field
- payment-provider-ready disabled CTA (no payment is falsely claimed as active)
- explicit note that displayed contribution tiers are local suggestions, not live FX conversions
- explanation of what support helps fund
- SafePDFHub brand mark and existing site header/footer
- responsive layouts for desktop, tablet and mobile

## Payment status

The page intentionally does **not** collect money yet. The production payment provider will be connected only after the merchant structure, KYC, GST/export requirements and settlement flow are finalized.
