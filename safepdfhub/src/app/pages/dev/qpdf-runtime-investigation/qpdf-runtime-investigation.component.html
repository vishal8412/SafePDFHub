R5 interpretation: the investigation is now repeat-safe. The exact PDF is cached by SHA-256 after a completed run, so the same known OOM boundary is not repeatedly re-triggered. Baseline PDF output establishes whether qpdf can create any transformed PDF from this input. If it passes, each following probe adds one independent capability: stream compression, Flate recompression, object streams, and image optimization. A failure identifies the first operation that crosses the observed runtime boundary; later probes are intentionally skipped rather than generating repeated high-risk failures.
